# `example-nft`

Running example minimale per costruire il nuovo orchestratore passo per passo.

Per scelta, qui non usiamo ancora la struttura completa del framework storico.
Partiamo con pochi file e aggiungiamo gli step solo quando servono.

## Flusso corto

1. definire cosa vogliamo studiare in `01-brief.json`
2. recuperare evidenza da Etherscan e Dune con prompt standardizzati
3. proporre MED e prima simulazione
4. fare review umana, correggere e confermare il launch

## File presenti adesso

- `experiment.json`: metadati minimi e stato del running example
- `01-brief.json`: brief iniziale, scritto e corretto insieme

## Regola operativa

Ogni file nuovo verra' introdotto solo quando il passo precedente e' abbastanza chiaro.
